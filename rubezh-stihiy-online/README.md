# Рубеж стихий — браузерная тактическая онлайн-игра (MVP)

Небольшой **играбельный сетевой прототип**, вдохновлённый принципами классических фэнтезийных карточных игр с полем 5×6. Это **не официальная игра «Берсерк» и не полная копия её правил**. Персонажи, дизайн и названия карт оригинальные.

## Что готово

- Игра прямо в браузере на Android, iPhone и компьютере, без установки APK.
- Два человека играют друг против друга в реальном времени: **создать комнату → поделиться ссылкой → набрать отряд → расставить карты → сражаться**.
- Поиск свободного соперника по кнопке «Найти соперника» (только среди посетителей именно этого сервера).
- Можно тренироваться против простого бота.
- Поле из 5 столбцов и 6 рядов. Расстановка в своём секторе (первый игрок — в трёх центральных столбцах своей половины).
- Набор отряда за два типа кристаллов, элитные и рядовые карты, 12 оригинальных типов существ.
- Пошаговые передвижения (по вертикали и горизонтали), атаки на ближней и дальней дистанции, бросок d6, здоровье, победа после уничтожения отряда.
- Сервер проверяет действия, игрок не может передвигать карты соперника; расстановка скрыта до начала боя. Режим восстановления соединения после перезагрузки вкладки.

## Чего пока нет

- Подлинных карт, иллюстраций и полного набора механик классической коллекционной карточной игры «Берсерк», включая все эффекты, стек, броски защиты, комбинированные действия, альтернативные варианты формирования отрядов, управление колодами 30–50 карт.
- Регистрации и долговременных аккаунтов, рейтинга, переписки, турниров, коллекций карт, покупок.
- Постоянного хранения партий и комнат: данные находятся в оперативной памяти сервера. При перезапуске бесплатного хостинга комнаты исчезают.
- Защиты от одновременного использования профиля на нескольких устройствах; для публичной игры понадобится полноценная система учётных записей и ограничение запросов.

## Установка локально

Установи [Node.js](https://nodejs.org/) версии 18+.

```bash
npm start
```

Открой `http://localhost:3000` в браузере. Для двух игроков можно открыть сайт в двух разных браузерах или на двух устройствах в одной сети (используя IP компьютера вместо `localhost`).

Проверка:

```bash
npm test
```

## Как сделать игру доступной в интернете

1. Создай **новый отдельный репозиторий GitHub**, загрузи в него содержимое этой папки. Не добавляй эти файлы в репозиторий с бухгалтерской системой.
2. На [Render](https://dashboard.render.com/web/new) создай **Web Service** с новым репозиторием.
3. Параметры: `Runtime: Node`, `Build Command: npm install`, `Start Command: npm start`, план `Free` для ознакомления.
4. После развёртывания открой публичный URL вроде `https://имя-сервиса.onrender.com/` на телефоне, нажми «Создать комнату», скопируй ссылку другу.

В бесплатном тарифе Render сервер может засыпать и перезапускаться: **активные партии и комнаты будут теряться**. Для полноценного онлайн-сервиса нужны постоянное хранилище данных, защита от злоупотреблений и сервер без засыпания. Если необходима бесплатная стабильная альтернатива, архитектуру стоит адаптировать под подходящий managed realtime backend (например, Firebase/Supabase с учётом лимитов и доступности).

## Технические детали

- Чистый Node.js HTTP-сервер, никаких внешних npm-пакетов.
- **Server-Sent Events (SSE)** передают состояние двум игрокам почти сразу; команды выполняются через JSON POST API.
- Состояние партии и ресурсы контролируются сервером.
- Для локального тестирования можно играть против бота.
- Комната автоматически удаляется после 8 часов отсутствия активности (или при рестарте сервера).

## Правовые ограничения

Название «Берсерк», официальные арты, тексты карт и оригинальная игровая продукция принадлежат соответствующим правообладателям. Для публичного распространения точной копии их содержимого необходима оценка прав и/или разрешение. Этот прототип использует только обобщённые игровые идеи, собственные имена существ и интерфейс.
