# Окунев — заказ по Excel-прайсу

Сайт с общим каталогом, поиском, корзиной и оформлением заказа в Excel. Владелец загружает прайс, покупатель выбирает товары и количества, скачивает готовый `.xlsx` или отправляет его на почту владельца. Интерфейс работает с Python-сервером FastAPI; каталог хранится в SQLite.

В репозитории находятся код приложения и начальный каталог из предоставленного прайса — 12 428 товаров. Для доступа через интернет приложение запускается на Python-хостинге.

## Локальный запуск

Нужен Python 3.11 или новее. Выполняйте команды из корня репозитория:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

В Windows активируйте окружение командой `.venv\Scripts\Activate.ps1` в PowerShell, а файл настроек создайте командой `Copy-Item .env.example .env`.

Откройте `.env` и задайте длинный уникальный `ADMIN_TOKEN`. Это пароль владельца для загрузки и замены общего прайса. Случайный пароль можно создать командой:

```bash
python -c "import secrets; print(secrets.token_urlsafe(32))"
```

Затем запустите приложение:

```bash
uvicorn app:app --host 0.0.0.0 --port 8000
```

Откройте [http://localhost:8000](http://localhost:8000). Проверка работоспособности сервера: [http://localhost:8000/health](http://localhost:8000/health).

## Настройки

Приложение читает `.env` рядом с `app.py`. При размещении на сервере те же значения можно задать в переменных окружения: они имеют приоритет над `.env`. После изменения настроек перезапустите сервер.

| Переменная | Назначение |
| --- | --- |
| `ADMIN_TOKEN` | Пароль владельца для импорта прайса. Без него загрузка выключена. |
| `DATA_DIR` | Каталог с базой `catalog.sqlite3`; в примере — `./data`. |
| `INITIAL_CATALOG_FILE` | Необязательный JSON-снимок для заполнения пустой базы. Для предоставленного прайса — `seed/catalog.json`. Существующий каталог не заменяется. |
| `ORDERS_TO` | Получатель заказов. В `.env.example` задан `aleksandr0397@bk.ru`. Несколько адресов разделяются запятыми. |
| `SMTP_HOST` | Адрес SMTP-сервера почтового отправителя. |
| `SMTP_PORT` | Порт SMTP: обычно `587` для STARTTLS или `465` для SSL/TLS. |
| `SMTP_SECURITY` | `starttls` или `ssl` для защищённого соединения. |
| `SMTP_USER` | Учётная запись отправителя, обычно полный адрес его почты. |
| `SMTP_PASSWORD` | Пароль приложения, созданный в настройках почтового отправителя. |
| `SMTP_FROM` | Адрес отправителя, разрешённый его почтовым сервисом. Если пустой, используется `SMTP_USER`. |

Для отправки писем получите настройки SMTP у почтового сервиса отправителя и создайте отдельный пароль приложения. Укажите сервер, порт, способ шифрования, логин, пароль и разрешённый адрес отправителя в `.env`. Адрес получателя заказа и адрес отправителя могут принадлежать разным почтовым ящикам.

Сервер отправляет настоящее письмо через SMTP и прикладывает сформированный Excel-файл. Заполненные настройки включают возможность отправки в интерфейсе; успешность подключения и приём письма почтовым сервером проверяются при отправке заказа. При отсутствии настроек покупатель может скачать Excel. Сообщение об успешной отправке означает, что SMTP-сервер принял письмо; окончательную доставку можно проверить в почте получателя.

Файл `.env` и каталог `data/` исключены из Git. Храните пароль владельца и почтовые секреты в настройках сервера или локальном `.env`.

## Прайс и оформление заказа

1. Владелец открывает загрузку прайса, вводит `ADMIN_TOKEN` и выбирает файл `.xlsx` или `.xls`.
2. Сервер распознаёт названия и цены, сохраняет общий каталог в базе и показывает результат импорта. Новая успешная загрузка заменяет предыдущий каталог.
3. Покупатель ищет товары, задаёт количества и проверяет корзину.
4. Покупатель при желании указывает имя, контакт для связи и комментарий, затем скачивает Excel-заказ или отправляет его владельцу. Эти поля необязательны.

Поддерживается согласованный прайс с заголовками во второй строке: `Наименование`, `Заказ↓`, `Ед. изм.`, `Цена`, `Сумма`. Для импорта обязательны столбцы названия и цены; строка заголовков ищется среди первых 50 строк. Единицы измерения и артикул распознаются при наличии соответствующих столбцов. Цены могут быть числами или текстом с десятичной запятой, например `12,50`.

Ограничения импорта: файл до 10 МБ, до 20 000 товарных позиций. Используется первый лист с распознанными заголовками и товарами. Пустые строки пропускаются; строки без названия или корректной цены учитываются как пропущенные. Ошибка импорта сохраняет предыдущий каталог.

Файл заказа формируется из выбранных позиций. На листе `Заказ` сохраняются порядок и названия пяти столбцов исходного шаблона: `Наименование`, `Заказ↓`, `Ед. изм.`, `Цена`, `Сумма`; сверху ставится дата, в конце — итог. На листе `Информация` находятся номер заказа, время, имя, контакт и комментарий покупателя. Цены и суммы рассчитываются сервером по текущему каталогу.

В заказе допустимо до 500 разных позиций. Количество должно быть больше нуля, не больше `999999` и содержать до трёх знаков после запятой. Если владелец обновил прайс во время оформления, сервер просит собрать заказ по новой версии каталога.

Исходный Excel-файл не добавляется в репозиторий и не сохраняется как статический файл сайта. При импорте в базе остаются распознанные товары; названия и цены доступны покупателям через каталог.

## Размещение на сервере

Для бесплатной версии на Render создайте отдельный Web Service из этого репозитория: runtime `Python`, branch `main`, build command `pip install -r requirements.txt`, start command `uvicorn app:app --host 0.0.0.0 --port $PORT`, plan `Free`. Задайте `DATA_DIR=./data`, `INITIAL_CATALOG_FILE=seed/catalog.json`, `ORDERS_TO=aleksandr0397@bk.ru` и собственный длинный `ADMIN_TOKEN`. Секреты задаются в Environment сервиса и не добавляются в Git.

В `seed/catalog.json` сохранены только поля публичного каталога, полученные из исходного прайса. На первом обращении пустая база автоматически получает 12 428 товаров. Паролей, заказов покупателей и исходного Excel-файла в снимке нет.

Бесплатный Render подходит для просмотра: после простоя первый запуск может занять около минуты. Его файловая система временная. После перезапуска или новой публикации база восстанавливается из начального снимка; заменённый через сайт прайс может сброситься. Для постоянной работы с обновляемым прайсом нужен постоянный диск или внешняя база.

Нужен хостинг, который запускает Python-приложение и предоставляет постоянный доступный для записи каталог для `DATA_DIR`. Подключите его к постоянному диску: в этой папке находится база общего прайса. Для сохранности каталога делайте резервные копии базы и сохраняйте этот каталог при обновлении приложения.

Настройте переменные окружения, запустите FastAPI приведённой выше командой и включите HTTPS. Веб-интерфейс и API обслуживаются одним приложением. Перед открытием сайта покупателям загрузите актуальный прайс и проверьте получение тестового заказа с Excel-вложением на `aleksandr0397@bk.ru`.

## Проверка

```bash
python -m unittest discover -s tests -v
```

Тесты проверяют импорт, защиту загрузки, сохранение каталога, формирование заказа, обработку старой версии прайса и отправку Excel-вложения через подменённый SMTP-сервер. Они используют временную базу и не отправляют реальные письма.
